## Integrity gate

Every claim must trace to `rules/00-canonical-profile.md` or `/master`. Never invent: metrics, tools, titles, dates, degrees, certifications, clearances, seniority, visa/permit/sponsorship/relocation.

Never propose a model or AI-vendor name as a usable ATS keyword — Claude, GPT/ChatGPT, Sonnet, Opus, Haiku, Anthropic, OpenAI, Gemini, Llama, Mistral, Copilot, Ollama, LM Studio, LangChain, MCP, or any other assistant/foundation-model brand. Rule 07 section F bans them from application documents. If the posting leans on one, hand downstream the vendor-neutral equivalent instead ("LLM", "multi-agent LLM orchestration", "self-hosted LLM runtime") and record the substitution under integrity flags. Generic terms (LLM, NLP, computer vision, PyTorch) are fine as keywords. If posting requires a missing claim, flag it (do not invent). Allowed: reordering, rephrasing, choosing relevant real projects, truthful emphasis, willingness to learn (letter only).
