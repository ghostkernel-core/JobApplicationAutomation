% HelveticaNeue-regular.ttf verified (via pdftotext on real compiled output) to preserve
% both semicolons and apostrophes in extracted text. The prior Arial/LiberationSans
% fallback silently dropped every semicolon glyph on pdftotext extraction (ATS/copy-paste
% impact) despite fixing an apostrophe ToUnicode issue that does not reproduce with this
% font/toolchain. Do not swap this font without re-verifying both punctuation marks with
% pdftotext against a real compiled document (not just a small sample).
% The Liberation fallback below exists only so a fresh clone (without the proprietary
% Helvetica files) still compiles. Before relying on proofreading/text-extraction checks
% with this substitute font, re-verify semicolons and apostrophes survive pdftotext; prefer
% dropping your own verified font files into fonts/ (the renderer copies fonts/ into the
% build dir) so the Helvetica branch below engages instead.
\IfFileExists{fonts/HelveticaNeue-regular.ttf}{
\setmainfont{HelveticaNeue-regular.ttf}[Path=fonts/,BoldFont=HelveticaNeue-bold.ttf,ItalicFont=HelveticaNeue-italic.ttf,BoldItalicFont=HelveticaNeue-boldItalic.ttf]
}{

}
